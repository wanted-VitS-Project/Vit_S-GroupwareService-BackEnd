## 0. 공통 규약

### 0-1. 이 도메인의 대전제 — 화면이 두 개다

| 화면 | 누가 | 무엇을 |
|------|------|--------|
| **재무 탭** (P-40·P-41·P-42·P-44) | 재무만 (`page_code='FINANCE'`) | 등록 · 수집 · 매칭 · 확정 · 연결 — **쓰기 전부** |
| **프로젝트 스텝 블록** (P-22A) | 프로젝트 참여자 | **읽기만.** 스텝 `EDITOR` 여도 쓰기 403 |

⛔ **블록 쪽 UI 에 확정·연결·발행 버튼을 만들지 마라** (PCB-003 · TXL-006 · INV-01).
⛔ **실무자용 화면에 재무 API 를 호출하는 경로 자체를 만들지 마라** (MTC-007 · INV-06).

### 0-2. 책임 원칙

| 구분 | FE | BE |
|------|----|----|
| 입력 검증 | 즉시 피드백용 1차 | **최종 판정** |
| 권한 | `FINANCE` 없으면 **탭 자체를 렌더하지 않는다** | 403 으로 차단 |
| 수집 | 진행률·결과 리포트 표시 | 부분 성공 집계 (전체 롤백 금지) |
| 매칭 | 후보를 보여주고 **사람이 누르게** 한다 | 자동 확정 경로를 **코드에 두지 않는다** |
| 파괴적 동작 | 확인 모달 필수 | 잠금 검사 후 실행 |

### 0-3. 전 API 공통 분기

```
401 AUTH_UNAUTHENTICATED   → 로그인 페이지
403 FINANCE_ACCESS_DENIED  → 재무 탭 진입 차단 (메뉴에서도 감춘다)
403 FINANCE_EDIT_DENIED    → 토스트 + 쓰기 버튼 영구 비활성
403 STEP_ACCESS_DENIED     → 스텝 화면으로 되돌림
404 *_NOT_FOUND            → 토스트 + 목록에서 제거
409 *                      → 원인 + **다음 행동**을 함께 안내
502 HOMETAX_API_FAILED     → "CSV 로 올려주세요" 대안 제시
```

✅ 인증 방식 확정 (2026-08-04) — **HttpOnly 세션 쿠키**. [`PRJ-V1-API-FLOW.md`](../프로젝트/PRJ-V1-API-FLOW.md) §0-2 와 동일.

## 1. 입금 — 등록 · 확정 (P-40)

### 1-1. 입금 목록 조회 — `GET /api/v1/payments`

```
FE (P-40 입금 내역)                             BE
──────────────────────────────────────────────────────────────
재무 탭 진입 / 필터 변경
    │
    ├─ ① 사용자에게 FINANCE 권한이 없으면
    │     **메뉴에서 재무 탭 자체를 감춘다** (PAY-009)
    │
    ├─ ② 필터 UI: 기간 · 매칭 여부 · 프로젝트
    │
    ├─ GET /api/v1/payments?matched=false → ① 인증 검증 → 401
    │                                       ② page_permission FINANCE 조회
    │                                          └ 행 없음 → 403 FINANCE_ACCESS_DENIED
    │                                       ③ 필터 적용
    │                                       ④ **정렬은 서버가 고정**
    │                                          project_id IS NULL 우선 → 입금일 DESC (PAY-004)
    │                                  ←── 200 {content[], totalElements}
    │
    └─ ③ 응답 분기
          200 → 표 렌더
                · 미매칭 행을 **시각적으로 강조** (떠도는 돈이 먼저 보여야 한다)
                · sourceType 뱃지 (직접등록 / CSV) 표시 (IMP-007)
                · ⛔ **정렬 헤더로 미매칭 우선을 깨지 마라** — 기본 정렬을 유지
          403 → 재무 탭 접근 차단 (뒤로가기)
```

### 1-2. 입금 상세 조회 — `GET /api/v1/payments/{paymentId}`

```
FE (P-40 행 클릭 · 사이드 패널)                 BE
──────────────────────────────────────────────────────────────
행 클릭
    │
    ├─ GET /api/v1/payments/301 ──────────→ ① 인증 검증 → 401 · FINANCE → 403
    │                                       ② 입금 조회 → 404 PAYMENT_NOT_FOUND
    │                                       ③ project · block · 확정자 조인
    │                                  ←── 200 {paymentId, project, block, ...}
    │
    └─ ② 응답 분기
          200 → 패널 렌더 + **다음 행동 버튼을 상태로 결정**
                project=null           → [프로젝트 매칭] 노출
                project 있고 block=null → [블록 연결] 노출 (선택 단계임을 문구로 명시)
                block 있음              → [연결 해제] 만 노출
                                          매칭 해제·삭제 버튼은 **비활성 + 사유 툴팁**
          404 → 패널 닫기 + 목록에서 제거
```

### 1-3. 입금 직접 등록 — `POST /api/v1/payments`

```
FE (P-40 [입금 등록])                           BE
──────────────────────────────────────────────────────────────
[입금 등록] → 모달 → [저장]
    │
    ├─ ① 입금일 · 금액 필수 표시, 금액 0 이하 인라인 에러
    │
    ├─ ② ⚠️ **프로젝트 선택 필드를 필수로 만들지 마라**
    │     모르는 상태로 등록하는 것이 정상 경로다 (PAY-003 · INV-04)
    │     모달에 "나중에 매칭할 수 있습니다" 안내
    │
    ├─ POST /api/v1/payments ─────────────→ ① 인증 검증 → 401
    │   {paidAt, amount, bankMemo,          ② FINANCE + EDITOR → 403 FINANCE_EDIT_DENIED
    │    payerName, bankTxnId?}             ③ paidAt/amount 누락 → 400
    │                                       ④ 금액 0 이하 → 400 PAYMENT_AMOUNT_INVALID
    │                                       ⑤ bankTxnId 있으면 중복 검사 → 409
    │                                       ⑥ payment INSERT
    │                                          project_id=NULL · source_type='MANUAL'
    │                                  ←── 201 {paymentId, sourceType:"MANUAL"}
    │
    └─ ③ 응답 분기
          201 → 목록 맨 위(미매칭 구역)에 추가 + 모달 닫기
                **경고 배너를 띄우지 마라** — 미매칭은 정상이다
          409 → "이미 수집된 거래입니다" 토스트
```


| 2 | **입금 등록 시 프로젝트를 필수로 만들지 마라** | 돈은 블록·프로젝트 판단보다 먼저 들어온다 | PAY-003 · INV-04 |

| 4 | **CSV 결과는 토스트가 아니라 리포트 모달** | 실패·건너뜀 행을 못 보면 조용히 누락된다 | IMP-004 · TAX-003 |
