### 1-5. 🚨 `page_permission` 은 2코드만 넣는다

> ⛔ vitawear 판 `09_page_permission.sql` 의 15행 중 12행이 지금 카탈로그 기준으로는 만들면 안 되는 행이다.

## 2. ⭐ 입찰(bid) 도메인 — 이 판의 시작점

vitawear 판은 `project.bid_notice_id` 가 전부 NULL 이다. KDT 는 **공고에서 시작하는 시나리오**라
이 도메인이 그대로 맞는다. 시연 동선이 하나로 이어진다.

```
공고 직접 등록 → AI 요약(확정) → 사내 기준자료와 비교 검토 → 프로젝트로 전환 → 서류 작성 → 결재 → 외주 정산
```

### 2-1. `bid_notice` 7건

| id | 출처 | 공고명 | 비고 |
|---|---|---|---|
| **8001** | **MANUAL**(직접 등록) | 2026년 K-디지털 기초역량훈련 심사 계획 공고 | ⭐ 메인 · `owner_company_id = 3` |
| 8002~8007 | NARA(수집) | 지자체 디지털 역량교육 위탁 용역 등 6건 | 관심 1 · 제외 2 |

⚠️ **8001 은 나라장터 공고가 아니다.** HRD-Net·직업능력심사평가원 누리집 공고라 수집 대상이 아니고,
담당자가 **직접 등록**하는 게 정확한 표현이다. `crawl_source_id = 2 (MANUAL)` · `owner_company_id = 3`.

8001 핵심 값:

| 컬럼 | 값 |
|---|---|
| `notice_ord` / `external_id` | `제2026-53호` 형식 |
| `notice_agency` | 직업능력심사평가원 |
| `demand_agency` | 한국기술교육대학교 |
| `announced_at` | 2026-07-31 |
| `bid_start_at` | 2026-08-03 10:00 |
| `application_deadline_at` | **2026-08-25 18:00** |
| `contract_method` / `evaluation_method` | 심사 신청 / 기본심사 + 과정심사(서면·현장) |
| `participation_qualification_text` | 신청자격 ①~④ 요약 |
| `base_amount` · `estimated_amount` | **NULL** — 발주 금액이 아니라 훈련비 단가 체계다 |
| `has_attachment` | 1 |

> ⚠️ `base_amount` 에 수강료를 넣지 마라. 이건 계약금액 칸이지 단가 칸이 아니다.
> 단가(12,100원/h)와 최대 수강료는 AI 요약 `amount_summary` 로 들어간다.

### 6-2. ⭐ `결재 대기` 탭을 채우려면 `ACTIVE` 를 흩뿌려야 한다

→ `IN_PROGRESS` **스텝**에만 붙인다.

⚠️ 이 두 규칙이 부딪힌다. 진행 중 스텝이 10개인데 그중 결재 블록이 있는 게 5개뿐이면

### 🚨 아직 안 한 것 — DB 적용과 검증

SQL 은 다 만들었지만 **어느 DB 에도 적용하지 않았다.** 즉 `99_verify.sql` 을 한 번도 돌리지 않았다.

파일 간 ID 참조와 불변식은 원문 파싱으로 대조해 통과했지만, 아래 셋은 **실제로 넣어봐야 안다.**

| 못 잡은 것 | 어떻게 드러나나 |
|---|---|
| ENUM·컬럼 길이·CHECK 제약 위반 | INSERT 자체가 실패한다 |
| 8000번대가 대상 DB 에서 비어 있는지 | `INSERT IGNORE` 라 조용히 스킵되고 화면만 이상해진다 |
| 역할 게이트(§1-4) | DB 카운트는 멀쩡한데 API 가 403 을 준다. `scope=drafted`·`scope=pending` 을 직접 호출해라 |

### 틀려도 눈에 안 보이는 것

| 확인 | 틀리면 |
|---|---|
| 훈련비 계산서 `tax_amount = 0` | 면세 과정에 부가세가 붙는데 **화면은 정상으로 보인다** |
| `actual_amount` = 연결 `cash_flow` 합계 | `PARTIAL` 인데 숫자는 완납이다 |
| `issue_block` 이 같은 스텝인가 | 카드엔 진척률이 뜨는데 스텝 진척률엔 안 들어간다 |
| `col_span` 합이 행마다 3 | 빈칸이 생기거나 블록이 다음 행으로 밀린다 |
| `act` 가 소문자인가 | `'CREATE'` 는 ENUM 위반으로 **INSERT 자체가 실패**한다 |
| `page_permission` 에 GRANTABLE 아닌 코드 | 행은 들어가는데 화면 판정에 아무 영향이 없다 |
| ⛔ `activity_log` 는 되돌릴 수 없다 | `deleted_at` 이 없다 — 마지막에 넣어라 |
