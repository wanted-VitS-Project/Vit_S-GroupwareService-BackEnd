## 0. 작성 규칙

### ✅ 여기에 쓴다

- 리소스의 **역할**과 **구조** (무엇이 왜 있는가)
- 포트 번호, 인스턴스 타입, 볼륨 크기
- 시크릿의 **키 이름** (`DB_PASSWORD`)
- 서비스 간 연결 관계

### ❌ 여기에 쓰지 않는다

| 금지 | 대신 |
|------|------|
| 퍼블릭/프라이빗 IP | `{{EC2_HOST}}` |
| RDS·Redis 엔드포인트 | `{{RDS_ENDPOINT}}` |
| 도메인 | `{{DOMAIN}}` |
| AWS 계정 ID · ARN | `{{AWS_ACCOUNT_ID}}` |
| 키페어 이름 | `{{KEY_PAIR}}` |
| 시크릿 **값** | 키 이름만 기록 |

> **AI에게**: 이 문서에 없는 리소스 이름·엔드포인트를 추측해서 지어내지 마라.
> 없으면 "INFRA.md에 없음 — 확인 필요" 라고 말할 것.
